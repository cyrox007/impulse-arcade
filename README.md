# ИМПУЛЬС — браузерный арканоид

**Версия:** 1.0.0-rc.1 — релиз-кандидат в `develop`, готовится ручная приёмка перед стабильным 1.0.

Оригинальный арканоид на JavaScript и Canvas 2D. Игра не использует внешние библиотеки.

## Структура и принципы разработки

Архитектура, разделение ответственности, порядок симуляции и ограничения рефакторинга описаны в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Рабочая интеграционная ветка — `develop`; `main` обновляется только после итоговой ручной приёмки стабильной версии.

## Запуск
Откройте `index.html` в браузере или разверните каталог на любом статическом веб-сервере.

- **ПК:** мышь или стрелки/A, D; пробел запускает шар; F — пробивной импульс; P/Esc — пауза.
- **Телефон:** управление платформой пальцем по игровому полю; дополнительные кнопки под полем.
- **Звук:** по умолчанию выключен.

## Игровые возможности к релиз-кандидату 1.0

Пять секторов, кирпичи нескольких типов, усиления платформы и шара, бонус жизни, энергия и пробивной импульс, счёт, рекорд, пауза, победа и поражение.

## Релиз-кандидат 1.0.0-rc.1 — финальная полировка

- **Настройки:** кнопка ⚙ в шапке открывает компактную панель с громкостью 0–100%, выбором графических эффектов (авто / полные / уменьшенные) и чувствительностью платформы 70–130%. Звук можно включить/выключить кнопкой ♫.
- **Сохранение настроек:** отдельный `localStorage` ключ `impulse-arcade:settings:v1`; изменения сохраняются между перезагрузками и не удаляются при начале новой кампании. Блокировка хранилища не мешает игре.
- **Пауза:** при настройке во время игры физика останавливается; закрытие панели не запускает мячи самопроизвольно. Возобновление через «Продолжить». Escape закрывает настройки.
- **Контроль проходимости:** отдельные тесты проверяют, что после уничтожения обычных кирпичей у направленных целей остаётся возможная последовательность попаданий; сохраняются геометрические проверки до стен.
- **Стресс-тесты:** смешанная частота симуляции, до трёх шаров, снаряды боссов, патрули, эффекты и бонусы без переполнения бюджетов. Ручное измерение реальных FPS и полное прохождение на физическом Android ещё обязательны.
- **Статус:** это RC, а не подтверждённая стабильная 1.0. План окончательной приёмки — `docs/RELEASE-1.0-QA.md`. `main` не меняется до проверки игроком.

## Новое в версии 0.9.0 — сохранение кампании

- **Автоматическая контрольная точка:** при успешной очистке сектора сохраняется старт следующего сектора с накопленными очками, жизнями, зарядом импульса и статистикой забега. Это не сохранение в середине боя: все кирпичи и боссы следующего сектора появляются в исходном состоянии.
- **«Продолжить» и «Новая игра»:** после перезапуска браузера на стартовом экране можно возобновить игру с последней контрольной точки или сознательно начать с первого сектора. При поражении разрешён повтор с контрольной точки. При победе и явной новой игре сохранение удаляется; личный рекорд сохраняется.
- **Надёжность:** отдельный версионированный ключ `impulse-arcade:checkpoint:v1` в `localStorage`, строгая проверка чисел/версии/диапазонов, безопасное поведение при повреждённом сохранении или запрете записи.
- **Границы:** сохранение хранится только в этом браузере и на этом устройстве, не синхронизируется и может пропасть при очистке данных сайта. Первый сектор без пройденных этапов начинается заново. Прогресс внутри текущего сектора, активные бонусы, шары и позиция босса не сохраняются.
- **Тесты:** Node-проверки очистки сектора, нового запуска, продолжения, поражения/победы, частичных и повреждённых данных; браузерная перезагрузка страницы с реальным `localStorage` на двух мобильных размерах поверх пяти основных экранов.

## Исправление 0.8.1 — невозможные направленные кирпичи

- Исправлена схема третьего сектора: крайний справа кирпич со стрелкой → больше не требует попасть снаружи стены; открыт снизу ↓.
- Аналогично исправлены направленные кирпичи возле крайних стен в последнем секторе. Внутренний блок с направлением → оставлен для разнообразия.
- Генератор уровня проверяет физическую ширину прохода шара (два радиуса + запас) до ближайшей стены. Если открытая грань физически недоступна, выбирает другую свободную грань. Проверка выполняется один раз при сборке карты, без дополнительных расчётов на кадре.
- Тесты проходят реальные столкновения со всеми направленными кирпичами в секторах 2–5 и воспроизводят заблокированный третий сектор со скриншота.
- Поскольку кампания пока не сохраняется, после обновления вкладки текущий забег придётся начать сначала.

## Новое в версии 0.8.0 — свободное движение и бой с ответным огнём

- **Односторонние блоки ↑ ↓ ← →** — броня с трёх сторон, попадание наносит урон только с направления, показанного стрелкой. Даже пробивной импульс отскакивает от закрытой грани; взрыв по соседству не уничтожает такие блоки.
- **Свободные патрули** — движущиеся кирпичи теперь размещены среди обычных на той же карте, без рельсов и отдельных нижних дорожек. Перемещаются по двум осям, периодически случайно меняют направление, отражаются от стен и других кирпичей. Движение не перерисовывает весь кэш статических блоков.
- **Страж ядра** теперь патрулирует по горизонтали и по вертикали, стреляет с предупреждением и уязвим в открытой фазе **только при ударе снизу**.
- **Реактор** расширил вертикальные перемещения, стреляет чаще Стража. Его три живых узла уязвимы только снизу. Пробивной импульс не обходит защиту при попадании с другого направления.
- **Снаряды** летят в сторону текущего положения платформы, ограничены 4 одновременно. При попадании в платформу расходуют одноразовый барьер либо одну жизнь. Пауза замораживает, смерть и переход сектора очищают.
- Сохранены 3 шара, бюджет 180 частиц и 24 волны, рендер боссов из готовых Canvas-спрайтов. Проверены управление, совместимость с бонусами и мобильная компоновка в Chromium.
- Цель физической проверки: стабильный 60 FPS на Android. Пользовательская приёмка требуется после публикации.

## Новое в версии 0.7.0 — пять секторов и два босса

- **Пять секторов:** два новых этапа «Призрачный коридор» и «Сердце реактора» после «Ядра станции». Между уровнями сохраняются очки, жизни и заряд, скорость и шанс бонусов постепенно растут.
- **Страж ядра** теперь завершает **третий** сектор: после победы над ним игра продолжается в четвёртом, а не заканчивается.
- **Финальный Реактор:** перемещающийся тяжёлый корпус с тремя различными уязвимыми узлами, по 2 HP каждый. Необходимо разрушить все три. Попадание по бронированной области отражает шар, в том числе при пробивном импульсе. Каждый узел имеет собственное визуальное состояние повреждения.
- **Графика:** уникальный заранее закэшированный спрайт Реактора, отдельные эффекты пробития узлов и уничтожения корпуса без тяжёлых покадровых градиентов.
- **Проверки:** Node и Chromium тестируют все пять секторов, промежуточную победу над Стражем и финального Реактора, паузу, мультишар и ограничение эффектов.
- **Неизменные ориентиры:** мобильное управление и пользовательский лимит 60 FPS. Ручную проверку новой кампании на физическом Android выполняет игрок.

## Новое в версии 0.6.0 — мультишар и магнит

- **Мультишар:** одновременно до 3 шаров, свои траектории и следы, общие бонусы скорости и импульса. Потеря одного шара не отнимает жизнь, пока остаётся хотя бы один другой. При потере основного другой автоматически становится основным.
- **Призма ✧:** новый фиолетовый блок во 2-м/3-м секторах, при уничтожении гарантированно разделяет шар (если их пока меньше трёх). Также может выпасть бонус мультишара ✳.
- **Энергоблок ⚡:** золотистый блок в третьем секторе, добавляет 42 единицы заряда импульса и дополнительные очки.
- **Магнит ∩:** ловит отбитый платформой шар, позволяет прицелиться и отпустить касанием поля, кнопкой или пробелом; для защиты от застревания автоматически отпускает через 1,2 секунды. Действует 12 секунд.
- **Карта:** новые расположения особых блоков в секторах 2 и 3; сохранены длинные патрули и Страж.
- **Бюджет:** 3 шара максимум, 180 частиц, 24 волны; движение патрулей обновляется один раз на физический подшаг. FPS диагностируется через `?fps=1`, а реальную Android-плавность ещё предстоит проверить.
- **Проверки:** 62 Node-теста и Chromium-smoke на 5 экранах, в том числе мультишар, магнит, независимая потеря мячей и Страж.

## Новое в версии 0.5.1 — настоящее движение и новый облик Стража

- **Длинные маршруты:** блоки патрулируют свободные полосы арены на сотни пикселей вместо колебания на ±4 px. В секторе 2 — два независимых горизонтальных патруля, в секторе 3 — волнообразный горизонтальный и отдельный вертикальный. Движение непрерывное, с сохранением превышения границ при отражении и независимостью от FPS.
- **Новый Страж ядра:** силуэт механического дрона с крыльями, бронепластинами и светящимся центральным ядром; закрывающиеся створки щита, круговой индикатор, парение, вспышки урона и 6 сегментов прочности.
- **Бережная графика:** состояния Стража предрисованы в два небольших Canvas-спрайта; движение блока не пересоздаёт слой статических кирпичей или градиенты каждый кадр. Сохранена поддержка уменьшенной анимации.
- **Проверки:** 51 Node-тест, 5 Chromium-конфигураций, включая проверку полного перемещения и обоих состояний Стража. Внешняя ручная проверка на Android по-прежнему нужна.

## Новое в версии 0.5.0

- **Движущиеся кирпичи ⇄** появляются во втором и третьем секторах. Они смещаются на коротких горизонтальных участках. Рисуются отдельно от кэшированного слоя статических кирпичей, поэтому не заставляют перерисовывать весь уровень каждый кадр.
- **Страж ядра:** после уничтожения всех кирпичей третьего сектора появляется цель с 6 HP и чередованием открытой (2,5 с) и защищённой (1 с) фаз. Только после уничтожения Стража засчитывается победа, награда и рекорд.
- **Финальный бой:** урон от обычного шара и импульса, отдельная индикация HP, эффекты повреждения и уничтожения. В защищённой фазе шар отражается, включая пробивной импульс.
- Сохранены пауза, счёт, комбо, бонусы и 3 сектора; ограничения частиц и волн, адаптивная компоновка и диагностика `?fps=1`.
- Проверки: **45 Node-тестов** и 5 браузерных конфигураций, включая прохождение боя. Реальный Android требует отдельной оценки плавности.

## Визуальная полировка 0.4.1

Каждый тип блока теперь разрушается по-своему:
- **Обычный:** голубые осколки и короткая световая волна.
- **Бронированный:** искры при повреждении, тяжёлые золотистые фрагменты и кольцо при уничтожении.
- **Энергетический:** две розово-фиолетовые волны.
- **Взрывной:** оранжевая ударная волна, направленные лучи и краткая вспышка; соседние блоки тоже показывают реакцию на урон.
- У эффектов общий бюджет **180 частиц и 24 волны**; отсутствуют новые покадровые градиенты, эффекты останавливаются на паузе, поддерживается `prefers-reduced-motion`.
- Новые 5 Node-тестов и браузерные сцены на 5 размерах экрана; измерение FPS на физическом телефоне остаётся за игроком.

## Новое в версии 0.4

- **Взрывные кирпичи** (✶) во втором и третьем секторах. При разрушении снимают 1 HP с четырёх ортогональных соседей; вторичные взрывы не образуют бесконтрольных цепочек.
- **Бонус «Барьер»** (⬡): одноразовая страховка от потери мяча. Показывается прямо на игровом поле, пропадает после срабатывания или при смене сектора.
- **Статистика забега**: игровое время, прямые попадания, разрушенные кирпичи, импульсы, лучшая серия и спасения барьером — на финальных экранах.
- Обновлены расстановки кирпичей в секторах 2 и 3. Сохранены физика, 60 FPS как целевой мобильный режим, кэш Canvas и компоновка.
- Автоматические проверки расширены для взрыва, барьера и статистики. Проверка на физическом Android остаётся отдельной.

## Новое в версии 0.3

- **Серии попаданий**: за успешные последовательные удары по кирпичам начисляется множитель очков от ×1 до ×4. Серия прерывается касанием платформы, потерей мяча или долгим отсутствием попаданий (6 секунд игрового времени); таймер стоит на паузе.
- **Бонус завершения сектора**: дополнительные очки за сохранённые жизни, показаны на экране перехода. Жизни, очки и рекорд по-прежнему сохраняются.
- **Защита от зацикливания траектории**: у мяча сохраняется достаточная вертикальная составляющая скорости, чтобы он не летал почти горизонтально бесконечно.
- **Усиления и комбо видны на поле**: компактная индикация оставшегося времени, без дополнительных панелей и уменьшения поля.
- Сохранены оптимизации отрисовки 0.2: кэширование фона, кирпичей и свечения мяча/платформы. При `?fps=1` доступна диагностика кадров на устройстве.

## Проверки
Требуется Node.js 20+:

```sh
npm run check
```

Проверяется синтаксис всех трёх игровых скриптов и весь набор Node-регрессий. Тесты разделены на `foundation`, `brick-effects`, `bosses`, `persistence`; общий стенд находится в `tests/support/game-harness.cjs`. Браузерная проверка выполняется отдельно через Python Playwright:

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/browser_smoke.py
```

В CI выполняются обе проверки (Node и Chromium). Протестированы desktop и 4 эмулированных мобильных viewport, но физический Android не проверялся.

**Приёмка текущего RC:** автоматические тесты проверяют пять секторов, обоих боссов, мультишар, сохранения, настройки, паузу и предельные сценарии физики. Реальное прохождение на Android, стабильность FPS и ручной баланс не подтверждаются эмуляцией и остаются обязательными до стабильной 1.0. Примеры проверок приведены в [docs/TESTING.md](docs/TESTING.md).

Учебный архив [The-Game](https://github.com/cyrox007/The-Game) не изменяется. Сценарии и приватный лор других проектов сюда не входят.
