## Исправления в ветке `develop` (01.11.2026)

- Коллизии с кирпичами теперь определяют сторону столкновения по краю шара, а не по его центру.
- Удар по центру платформы больше не создаёт абсолютно вертикальную траекторию.
- Второй палец не перехватывает управление уже активным касанием.
- Потеря фокуса и скрытие вкладки сбрасывают зажатые клавиши и указатель.
- Короткие экраны (320×568 и 360×640) показывают элементы управления и стартовое окно без обрезания.
- Добавлены 4 регрессионных теста и расширена UI-проверка до четырёх размеров экрана; добавлен отдельный CI-job для браузера.

Изменения **влиты в `main` через PR #1**; оба job GitHub Actions для PR завершились успешно. Это всё ещё не релиз 1.0, а статус Pages и проверки физического телефона остаются открытыми: см. Issues #2 и #3.

## Мобильный интерфейс — переработка по отзыву пользователя (01.11.2026)

По скриншоту реального Android стало видно: игровое поле заметно сужено из-за внешних карточек, шапки, заряда и высоких кнопок. Реализовано и слито **в `develop` через [PR #4](https://github.com/cyrox007/impulse-arcade/pull/4)**:
- мобильная шапка уменьшена; кнопки звука и паузы компактны;
- счёт, рекорд, жизни размещены поверх верхней части игрового поля;
- пропорции игрового Canvas 480×720 сохраняются, но в портрете поле использует почти всю возможную ширину и доступную высоту;
- заряд и главные кнопки уплотнены, подсказки на экране не занимают место, длинный footer скрыт;
- стартовое окно стало небольшим и не перекрывает большую часть игры;
- в Chromium smoke добавлены проверки минимальной ширины поля, пропорций, наложения HUD, доступности кнопок и отсутствия горизонтальной прокрутки.

**Проверено:** оба job GitHub Actions в PR #4 завершились успешно; в Chromium измерено игровое поле: 280×420 при 320×568, 333×500 при 360×640, 375×562.5 при 393×852. **Открыто:** визуальная проверка именно обновлённого UI на физическом Android (скриншот после обновления) и полноценное прохождение уровней. Тестовый сайт публикуется из `develop` согласно настройке пользователя. Скриншот прежнего UI уже подтвердил открытие сайта в мобильном браузере; новый внешний деплой пока не проверен.
