## Исправления в ветке `develop` (01.11.2026)

- Коллизии с кирпичами теперь определяют сторону столкновения по краю шара, а не по его центру.
- Удар по центру платформы больше не создаёт абсолютно вертикальную траекторию.
- Второй палец не перехватывает управление уже активным касанием.
- Потеря фокуса и скрытие вкладки сбрасывают зажатые клавиши и указатель.
- Короткие экраны (320×568 и 360×640) показывают элементы управления и стартовое окно без обрезания.
- Добавлены 4 регрессионных теста и расширена UI-проверка до четырёх размеров экрана; добавлен отдельный CI-job для браузера.

Изменения **влиты в `main` через PR #1**; оба job GitHub Actions для PR завершились успешно. Это всё ещё не релиз 1.0, а статус Pages и проверки физического телефона остаются открытыми: см. Issues #2 и #3.
