# ИМПУЛЬС — финальная приёмка 1.0

**Состояние:** 1.0.0-rc.1 (develop). Stable 1.0 и main пока не выпущены.

## Данные для воспроизведения

- Игра: https://cyrox007.github.io/impulse-arcade/
- Репозиторий: https://github.com/cyrox007/impulse-arcade
- Диагностика FPS: добавить `?fps=1` к адресу. Не включать в обычном запуске.
- При непонятном кэше перезагрузить страницу: заголовок должен показывать `1.0 RC`.
- `localStorage` хранит рекорд, контрольную точку (между секторами) и предпочтения; после очистки данных сайта они пропадут.

## Обязательные испытания на телефоне

- [ ] **Первый сектор:** запуск, сенсорное движение платформы, отсутствие потери контроля при повторном касании.
- [ ] **Второй сектор:** призматический блок/мультишар, магнит, взрывы, свободные движущиеся кирпичи.
- [ ] **Третий сектор:** односторонние блоки и право-крайняя стрелка ↓ (не должна заблокировать сектор), Страж ядра, уязвимая фаза и снаряды.
- [ ] **Четвёртый сектор:** направленные кирпичи со всех доступных сторон, нет неуничтожимых целей после очистки соседей.
- [ ] **Пятый сектор:** три уязвимых узла Реактора, защита корпуса, атаки, переход к экрану победы.
- [ ] **Сохранения:** после сектора 1 полностью закрыть/открыть страницу, проверить «Продолжить» со счётом/жизнями; «Новая игра» сбрасывает checkpoint, но не рекорд.
- [ ] **Настройки:** ⚙ показывает громкость/эффекты/чувствительность; на ходу ставит паузу, закрытие панели само не возобновляет; настройки переживают перезагрузку.
- [ ] **Управление и звук:** клавиатура/мышь на ПК, сенсор на Android, включение/выключение звука без падения FPS.
- [ ] **Пауза:** после сворачивания/уведомления/развёртывания движение заморожено, игрок сам возобновляет.
- [ ] **Экран:** портретный и альбомный режим — меню, настройки, кнопки и HUD доступны, ничего не выпадает за пределы.
- [ ] **Производительность:** на личном Android ~60 FPS во время максимальных эффектов, 3 шаров и выстрелов; зафиксировать максимум времени кадра, когда наблюдаются рывки.
- [ ] **Итог:** нет блокирующих ошибок и потерянного прогресса; согласовать баланс и финальную сложность.

## Автоматический контроль

- `npm run check`: синтаксис JS и Node-регрессии.
- `python tests/browser_smoke.py`: 5 размеров Chromium, плюс 2 проверочных мобильных сценария с реальным `localStorage` после перезагрузки.
- Проверки контролируют геометрию уязвимых граней, боевую физику, бюджеты частиц/волн/выстрелов, настройки и checkpoint.
- Браузерные тесты **не доказывают** FPS физического телефона и не заменяют тестирование в Firefox/Safari/Android Chrome.

## Критерии выпуска 1.0

1. Нет открытых блокирующих багов; найденные ошибки проверены повторно.
2. Все автоматические проверки последнего кандидата зелёные.
3. Пользователь подтверждает прохождение и отсутствие проблем на физическом Android.
4. Только после этого переносим принятый commit из `develop` в `main` и отмечаем стабильную версию 1.0.

Незакрытые задачи Android QA остаются в GitHub Issues. Не закрывать их автоматически на основании одних тестов.
